# AI Data Quality & Evaluation Pipeline

A practical data-quality pipeline for AI/ML datasets. It demonstrates validation, duplicate detection, missing-value checks, label consistency checks, and a transparent quality report.

## Skills demonstrated
- Python data processing
- AI/ML dataset preparation
- Data validation and quality metrics
- Error analysis
- Reproducible reporting

## Run
```bash
python pipeline.py sample_data.csv
```

The project is intentionally framework-light so the validation logic is easy to inspect and adapt to annotation and model-evaluation workflows.
