## Engineering principles

- **Evidence over claims** — document what was tested, what remains unverified, and how results were produced.
- **Humans stay in the loop** — automated evaluation should support accountable review.
- **Local-first when practical** — reduce unnecessary dependencies, cost, and data exposure.
- **Reproducibility matters** — prefer deterministic workflows, tests, CI, and inspectable artifacts.
- **Accessible by design** — treat keyboard and assistive access as product requirements.
