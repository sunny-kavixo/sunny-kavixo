- **Sunny Local AI / Sunny AI:** local-first desktop agent research on Apple Silicon, evidence-driven reasoning, tool execution and governed actions. Working features and planned capabilities require separate verification; no AGI claim.
- **[LittleLess AI / LittleBit Compression Research](https://github.com/sunny-kavixo/LittleLess-AI):** the public repository now contains Phase 4.1 native streaming code, tests, benchmark scripts, and CSV results for a small four-block, byte-level transformer; Phase 4.2 records three unsuccessful approaches. These are repository-reported experiments: the public checkout omits the model checkpoints, WikiText-2 data, and compiled library needed to reproduce its performance figures, and no external independent replication was verified here. The goal of running 20–30 GB-class open-weight models within a preferred 6 GB / maximum 8 GB *additional* RAM budget remains unproven; native heap figures are not whole-process memory or demonstrated large-model compression.
- **Principia Artificialis / EGRR:** research methodology and reproducibility proposals, with acceptance contingent on independent review and tests.

Some research artifacts are local or in development; links are provided only when a corresponding public repository or upstream PR is available.
